# 01. 프로젝트 초기 구축 (2026-11-18)

## 작업 내용
1. **저장소 구조**: `backend/`, `frontend/`, `ai/`, `data/`, `docs/`, `.github/workflows/` 구성, 단일 `.env` / `requirements.txt` 규칙 적용
2. **백엔드 (FastAPI)**
   - JWT 인증, PBKDF2 비밀번호 해시, 비밀번호 정책 검증
   - 권한: 일반 사용자 / 실제 관리자(ADMIN_SECRET_KEY) / 테스트 관리자(읽기 전용, `ReadOnlyGuardMiddleware` 403)
   - 주차면 현황·유도(최근접 경로)·내 차 찾기, 이벤트, 카메라, 모델, 감사 로그, 리포트(Gemini/템플릿)
   - WebSocket `/ws/parking` 실시간 푸시 + 데모 시뮬레이터, AI 추론 수집 API
   - pytest 13건
3. **AI 모듈**: 라벨 변환, 학습, 점유 판별(ROI 커버리지 + 다수결), OCR, 마스킹, 추론 파이프라인, pytest 5건
4. **프런트엔드**: 공통 Layout(헤더·드로어·푸터·Top 버튼), 13개 화면, 주차 상태 컬러 시스템, 다크 관제 테마, Mock 데모 모드
5. **배포**: Render Blueprint(`checksPass` + buildFilter), Netlify(`ignore` 규칙), GitHub Actions CI + Pages — Deploy Hook 미사용

## 검증
- 백엔드/AI 테스트 통과, 프런트엔드 프로덕션 빌드 성공
- Playwright(Edge)로 실 API 모드·Mock 모드 주요 화면 렌더링 및 테스트 관리자 읽기 전용 토스트 확인

## 이슈 및 해결
- 최신 Chromium 의 `window.scrollTo()` 가 Promise 를 반환 → useEffect 화살표 함수 반환값으로 인식되어 언마운트 시 오류 → 블록 함수로 수정
- 헤더 `backdrop-blur` 가 fixed 드로어의 기준 영역이 되는 문제 → `createPortal` 로 body 에 렌더링
- Windows pip 24 가 requirements.txt 를 cp949 로 읽는 문제 → 첫 줄 `# -*- coding: utf-8 -*-` 추가
