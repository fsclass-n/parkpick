주차장 CCTV와 AI Hub ‘주차 관련 이동체 인지 영상’ 데이터를 AI 객체 탐지·추적 모델로 분석해 주차면 점유를 실시간 판별하고, 운전자에게는 빈 자리 유도를, 운영사에게는 관제 대시보드를 제공하는 B2B 솔루션입니다.

서비스 바로가기 Netlify 데모 (Mock) API 문서 GitHub

주요 기능

실시간 관제

층·구역별 주차면 맵과 CCTV 영상 분석(바운딩 박스·추적 ID)을 WebSocket으로 실시간 갱신

주차 유도

입구에서 가장 가까운 빈 주차면(일반·장애인·전기차) 추천과 진입 경로 안내

내 차 찾기

번호판 OCR 인식 결과로 차량 번호만 입력하면 주차 위치·경과 시간 조회

관리자 · 운영 리포트

회원 권한 관리, mAP·인식률·점유율·회전율·혼잡도 통계, Gemini 운영 리포트
