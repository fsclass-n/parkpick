## 2. 비기능 요구사항

| ID | 구분 | 요구사항 |
|---|---|---|
| NFR-01 | 보안 | 비밀번호 PBKDF2-SHA256 해시, JWT(HS256) 인증, 보안 키는 환경 변수로만 관리 |
| NFR-02 | 보안 | 테스트 관리자 쓰기 요청 서버 일괄 차단(403), 관리자 작업 감사 로그 |
| NFR-03 | 개인정보 | 번호판·이메일 마스킹, 영상 번호판·얼굴 블러, WebSocket 브로드캐스트에 번호판 미포함 |
| NFR-04 | 성능 | 주차면 상태 변경 후 3초 이내 화면 반영 (WebSocket) |
| NFR-05 | 반응형 | Desktop / Tablet / Mobile 대응, 모바일 드로어 GNB |
| NFR-06 | 배포 | main push 시 영역별 자동 배포 (Render Blueprint, Netlify Git 연동, Deploy Hook 미사용) |
| NFR-07 | 품질 | GitHub Actions CI (pytest, 프런트 빌드) 통과 후 Render 배포 |
