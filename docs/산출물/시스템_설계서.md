# 시스템 설계서 (작성: 홍기흥)

## 1. 아키텍처

```
[CCTV / 샘플 영상]
      │  RTSP / mp4
      ▼
[ai/pipeline.py] YOLO 탐지 → ByteTrack 추적 → ROI 점유 판별 → 번호판 OCR
      │  POST /api/ingest/occupancy (X-Ingest-Token)
      ▼
[FastAPI parkpick-api] ── SQLAlchemy ──▶ [TiDB Cloud / SQLite]
      │  REST /api/*          │ pandas 통계        │ Gemini API (운영 리포트)
      │  WebSocket /ws/parking
      ▼
[React 프런트엔드] parkpick.onrender.com (실 API) / parkpick.netlify.app (Mock 데모)
```

- 영상 추론 연동 전에는 백엔드 시뮬레이터(`SIMULATOR_ENABLED=true`)가 입출차·이벤트를 생성해 실시간 흐름을 재현합니다.
- Netlify 데모는 `VITE_USE_MOCK=true` 로 `frontend/src/mock/server.js` 가 동일한 API·권한 규칙을 브라우저에서 모사합니다.

## 2. 백엔드 구조 (`backend/app`)

| 모듈 | 역할 |
|---|---|
| `main.py` | 앱 생성, CORS, 읽기 전용 미들웨어, 라우터 등록, 시드·시뮬레이터 기동 |
| `config.py` | 루트 `.env` 로드 및 설정 |
| `models.py` | ORM 모델 |
| `security.py` / `deps.py` / `middleware.py` | 해시·JWT / 권한 의존성 / 테스트 관리자 쓰기 차단 |
| `realtime.py` | WebSocket 연결 관리, 점유 반영, 시뮬레이터 |
| `services/` | `layout`(도면·경로), `stats`(pandas 통계), `report`(Gemini), `oauth`, `masking`, `audit` |
| `routers/` | `auth`, `parking`, `admin`, `reports`, `ingest`, `ws` |

## 3. 데이터 모델 (ERD 요약)

| 테이블 | 주요 컬럼 |
|---|---|
| users | id, email(UQ), name, password_hash, role(user/admin/test_admin), provider, plate, created_at, last_login_at |
| parking_lots | id, name, address, floors(JSON), entrance(JSON) |
| spaces | id, lot_id(FK), floor, zone, code(UQ), kind(normal/disabled/ev/reserved), status(empty/occupied), plate, x, y, occupied_since, updated_at |
| cameras | id, name, floor, zone, stream_url, roi(JSON), active |
| parking_events | id, kind(long_parking/illegal_parking/wrong_way), severity, space_code, plate, camera, message, status(open/resolved), created_at |
| entry_logs | id, plate, space_code, entered_at, exited_at, plate_confidence |
| model_configs | id, version, conf_threshold, metrics(JSON), active |
| reports | id, period(daily/weekly), title, content, source(gemini/template), created_at |
| audit_logs | id, actor_email, action, target, detail(JSON), created_at |

## 4. API 목록

| Method | Path | 권한 | 설명 |
|---|---|---|---|
| POST | /api/auth/signup · /login · /test-login · /admin-key-login · /logout | 공개 | 인증 |
| GET/PATCH | /api/auth/me | 로그인 | 내 정보 조회·수정 |
| GET | /api/auth/oauth/providers · /oauth/{provider}/login · /callback | 공개 | 소셜 로그인 |
| GET | /api/parking/lot · /spaces · /summary · /guidance · /find-car | 공개 | 주차 현황·유도·내 차 찾기 |
| GET | /api/parking/events/recent · /cameras | 로그인 | 최근 이벤트, 카메라 |
| GET | /api/admin/users · /dashboard · /events · /cameras · /models · /audit-logs | 관리자·테스트 관리자 | 관리자 조회 |
| PATCH/DELETE/POST/PUT | /api/admin/users/{id}/role · /users/{id} · /events/{id} · /spaces/{code} · /cameras · /models | 실제 관리자 | 관리자 쓰기 (감사 로그) |
| GET | /api/reports · /api/reports/stats | 로그인 | 리포트·통계 |
| POST/DELETE | /api/reports/generate · /api/reports/{id} | 실제 관리자 | 리포트 생성·삭제 |
| POST | /api/ingest/occupancy | 수집 토큰 | AI 추론 결과 수집 |
| WS | /ws/parking | 공개 | `space_update`, `event`, `event_update` 푸시 |

## 5. 배포 구성

| 서비스 | 플랫폼 | 설정 파일 | 트리거 |
|---|---|---|---|
| parkpick-api | Render Web Service (Python 3.11, free, singapore) | `render.yaml` | main push + CI 통과 (`checksPass`), `backend/**`·`requirements.txt` 변경 시 |
| parkpick | Render Static Site | `render.yaml` | `frontend/**` 변경 시 |
| parkpick (데모) | Netlify | `netlify.toml` | `frontend/`·`netlify.toml` 변경 시 |
| 안내 페이지 | GitHub Pages | `.github/workflows/deploy.yml` | main push |

- Render 무료 플랜은 15분 미사용 시 슬립되며 SQLite 데이터는 재배포 시 초기화됩니다. 운영 데이터 보존은 `DATABASE_URL` 에 TiDB Cloud 를 지정합니다.
