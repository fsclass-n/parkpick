# 데이터 분석 보고서 (작성: 이오리)

> 현재 분석 대상은 백엔드 시드(`backend/app/seed.py`)가 생성한 **7일치 가상 입출차 로그**입니다. 실제 CCTV 추론 데이터가 쌓이면 같은 로직(`backend/app/services/stats.py`)으로 재분석합니다.

## 1. 분석 지표 정의
| 지표 | 정의 | 구현 |
|---|---|---|
| 점유율 | 점유 주차면 / 전체 주차면 (층·유형별) | `occupancy_summary` (pandas groupby) |
| 시간대별 입출차 | 최근 7일 시간대별 입차·출차 대수 평균 | `value_counts().reindex(0~23)` |
| 혼잡도 | 정시마다 주차 중 차량 수 / 전체 주차면의 시간대별 평균 | NumPy 브로드캐스팅 (`entered ≤ t < exited`) |
| 회전율 | 일 입차 대수 / 전체 주차면 | 일별 groupby |
| 평균 주차 시간 | 출차 완료 차량의 (출차 − 입차) 평균(분) | pandas Timedelta |
| 번호판 인식률 | OCR 신뢰도 0.85 이상 비율 | `confidence >= 0.85` |

## 2. 가상 데이터 패턴
- 상업·오피스 복합시설 가정: 출근(8~9시), 점심(12~13시), 저녁(18~19시) 피크
- 주차면 96면 (B1·B2 × A~D 구역 × 12면), 장애인 4면·전기차 4면·예약 2면

## 3. 활용
- 관리자 대시보드·운영 리포트 화면의 차트 데이터 규격으로 사용
- Gemini 운영 리포트 프롬프트 입력(JSON 요약: 점유율, 층별 현황, 피크 시간, 회전율, 인식률, 미처리 이벤트)
- 향후: 공공데이터포털 주차장 정보 API로 주변 공영주차장 비교, 요일·날씨 변수 추가 혼잡도 예측
