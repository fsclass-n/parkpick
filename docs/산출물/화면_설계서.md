# 화면 설계서 (작성: 박미금)

| ID | 화면 | 경로 | 접근 | 주요 구성 |
|---|---|---|---|---|
| UI-01 | 메인 | `/` | 공개 | 히어로, 실시간 주차 현황 카드(LIVE), KPI 4종, 서비스 카드, 처리 흐름, 고객군, CTA |
| UI-02 | 로그인/회원가입 | `/login` | 비로그인 | Split 화면(좌: 브랜드 그래픽 / 우: 폼), 테스트 계정 버튼 2종, 비밀번호 규칙 실시간 체크, 소셜 로그인 3종, 관리자 보안 키 로그인 |
| UI-03 | 실시간 관제 | `/monitor` | 로그인 | 다크 테마 토글, KPI, 층 탭, 주차면 맵(상태 컬러·이상 이벤트 점멸), 이벤트 관제 패널, CCTV 영상 분석 뷰 |
| UI-04 | 주차 유도 | `/guide` | 공개 | 유형(일반·장애인·전기차)·층 선택, 추천 주차면·거리·단계별 안내, 대안 주차면, 경로 애니메이션 맵 |
| UI-05 | 내 차 찾기 | `/find-car` | 공개 | 차량 번호 입력, 위치·입차 시각·경과 시간, 보행 경로 맵 |
| UI-06 | 운영 리포트 | `/reports` | 로그인 | KPI, 시간대별 입출차·혼잡도 차트, 점유 도넛, 일별 회전율, AI 운영 리포트 목록·열람 |
| UI-07 | 마이페이지 | `/mypage` | 로그인 | 계정 정보, 이름·차량 번호 수정 (테스트 관리자 비활성) |
| UI-08 | 관리자 대시보드 | `/admin` | 관리자 | mAP·번호판 인식률·점유율·회전율 KPI, 시간대별 차트, AI 모델 성능 |
| UI-09 | 회원 관리 | `/admin/users` | 관리자 | 검색, 권한 변경(일반 ↔ 관리자), 삭제 |
| UI-10 | 이벤트 관제 | `/admin/events` | 관리자 | 상태 필터, 실시간 수신, 처리 완료/다시 열기 |
| UI-11 | AI 운영 리포트 | `/admin/reports` | 관리자 | 일간/주간 생성, 열람, 삭제 |
| UI-12 | 시스템 설정 | `/admin/settings` | 관리자 | CCTV 카메라·ROI, AI 모델 버전 적용, 감사 로그 |
| UI-13 | 정책 | `/policy/:kind` | 공개 | 이용약관, 개인정보처리방침, 영상정보처리기기 운영·관리 방침 |

## 공통 컴포넌트
- `Layout` (글로벌 헤더·푸터·Top 버튼), `Header` (GNB·알림·프로필·모바일 드로어), `Footer`, `TopButton`
- `ParkingMap` (SVG 주차면 맵), `VideoAnalysisView` (Canvas 탐지 오버레이), `Charts` (Recharts), `ReportPanel`, `Markdown`
- `ui.jsx`: `PageHeader`, `KpiCard`, `StatusLegend`, `Spinner`, `EmptyState`, `ErrorBox`

## 반응형 기준
- Mobile ≤767px: GNB → 햄버거 + 우측 드로어, 카드 1열
- Tablet ≥768px: 카드 2열
- Desktop ≥1024px: 12컬럼 그리드 (관제 8:4, 유도 4:8)
